1. Collapse the Skin Conversion Module into Assets

Strong in-process
src/converter.rs • src/assets.rs • src/main.rs • src/lib.rs
Problem

converter is a shallow module exposing one raw image transformation function, requiring callers to manually coordinate decoding, layout checks, and file writes.

Solution

Absorb converter entirely into assets as private implementation details of RawSkin and add format-preserving offline conversion methods.

Before: Shallow Module Leak

                    CLI[CLI convert] -->|opens DynamicImage| CONV[converter::single2double]

                    CONV -.leaks details.-> CLI
                    classDef leak stroke:#dc2626,stroke-width:2px;
                    class CONV leak;
After: Deep Assets Seam 
                  flowchart TD
                    CLI[CLI convert] -->|RawSkin::convert_file| ASSETS["RawSkin (Deep Module)"]
                    CALLER[Renderer / Upload] -->|RawSkin::from_file| ASSETS
                    subgraph ASSETS ["RawSkin (Deep Module)"]
                      direction TB
                      INTERNAL["private mirror & double-layer expansion"]
                    end
                    ASSETS -->|unified output| OUT[Disk File / Body]
                    classDef deep fill:#0f172a,stroke:#0f172a,color:#ffffff;
                    class ASSETS deep;
Architectural Wins
  • ✓ Locality: skin layout invariants concentrate in assets
  • ✓ Deletion test: passes; removes 1 shallow module and public export
  • ✓ Leverage: callers test complete asset lifecycle at one seam
  • ✓ CLI shrinks: CLI delegates path and save policy cleanly
